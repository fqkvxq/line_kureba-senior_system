1. システム全体概要

シニア向けパソコン教室向けLINE管理システムの目的と構成

当システムは、シニア向けパソコン教室において、受講生とのコミュニケーション向上、レッスンの無断欠席防止、定期的なパソコン・スマホのメンテナンス受診促進を実現するための専用管理システムです。
既存の「プロラインフリー（ProLine Free）」「エルメ（L-messh）」「LINE Harness（ラインハーネス）」等の外部マーケティングツールで構築された環境を壊すことなく、100%干渉ゼロで共存できる設計となっています。

A

受講生・カルテ管理画面 (index.html)

受講生一覧、受講コース（パソコン入門、スマホ活用、Word/Excelなど）、使用機器（Windows11、iPad等）、次回レッスン日・定期PC健康診断日・会員更新（月謝）期日の管理とリマインド配信を行います。

B

マルチWebhook中継ハブ (webhook.php)

LINE公式アカウントから届くWebhookイベントを本システムで瞬時に受講生カルテへ同期した上で、署名ヘッダー付きでプロライン、エルメ、LINE Harness等へ並列同時転送します。各ツールの自動応答・ステップ配信・シナリオ・分析機能に一切支障を与えません。

C

受講生向け マイカルテ & 予約画面 (LIFF / liff/mycar.html)

受講生がLINEのメニューからワンタップで開き、自分の受講コース、次回レッスン日時、PC健康診断の予定確認、受講予約やお困りごとの個別LINE相談ができます。

2. 外部マーケティングツール連携（プロライン / エルメ / LINE Harness等 並列中継・完全共存）

プロライン・エルメ・LINE Harness等の自動応答・ステップ配信・シナリオと本システムを100%干渉させずに共存させる設定手順

LINE公式アカウントの仕様上、LINE Developersコンソールに登録できるWebhook URLは1アカウントにつき1箇所しかありません。
そのため、直接プロラインやエルメ、LINE Harnessのいずれか1つのURLを登録すると他のツールや本システムにWebhookが届かなくなります。
当システムを「LINE中継ハブ」として位置づけ、受信したLINEの全メッセージ・友だち追加イベントを【プロライン】【エルメ (L-messh)】【LINE Harness】等の複数ツールへミリ秒単位で並列同時転送（マルチWebhookプロキシ中継）することで、すべてのツールの自動応答・ステップ配信・チャット通知を生かしたまま完全共存を実現します。

【メッセージ・イベントのリアルタイム並列中継フロー】
受講生のLINE ➡ [LINE公式アカウント]
  ⬇ (LINE Messaging API Webhook)
[本システム: webhook.php] ➡ 受講生カルテ・チャット履歴に自動同期＆未読管理・Slack/Discord通知
  ⬇ (並列非同期curl_multi転送 / 生署名X-Line-Signature完全付与)

├➡ [エルメ (L-messh): l-messh.com/...] ➡ シナリオ配信・フォーム・リッチメニューアクションが連動！
├➡ [LINE Harness: line-harness.com/...] ➡ 高度な顧客分析・自動トリガー配信が稼働！
└➡ [その他外部ツール: Zapier / Make / 自社Webhook等] ➡ 複数URLへも同時にリアルタイム配信！
1

管理画面で各外部ツール（プロライン / エルメ / LINE Harness等）のWebhook URLを登録

管理画面ヘッダーのアカウント名「⚙️ アカウント設定」をクリックして設定モーダルを開きます。

  • 転送先 Webhook URL一覧（1行に1件・複数登録可能）: 各ツールで案内されるWebhook URLを改行で入力します。
    ・プロライン: https://autosns.pro/api/webhook/...
    ・エルメ: https://l-messh.com/api/webhook/...
    ・LINE Harness: https://line-harness.com/api/webhook/...
    ※ 画面上の「＋ プロライン」「＋ エルメ」「＋ LINE Harness」チップを押すだけで簡単に入力・追加できます。
  • 「 この設定で保存する」ボタンを押します。
2

LINE DevelopersコンソールのWebhook URLを本システムに設定

LINE Developersコンソール にログインし、該当チャネルの「Messaging API設定」タブを開きます。

  • Webhook URL に本システムのURL（例: https://あなたのドメイン/webhook.php）を入力し「更新」を押します。
  • 「Webhookの利用」を「有効（ON）」にします。
  • 「検証」ボタンを押し、「成功」と表示されることを確認します。
3

疎通テストの実行と中継診断

ブラウザで https://あなたのドメイン/webhook.php を直接開くと、登録されているすべての転送先Webhook URLへの直近の転送ログやHTTP応答ステータス（OK (200) 等）をリアルタイムに確認できます。

4

外部ツールの通知やステップ配信が動かない場合のチェックリスト

  • 1. 転送先URLの登録確認：管理画面「アカウント設定」を開き、各ツールのWebhook URLに余分な空白や誤字がないかご確認ください。
  • 2. LINE DevelopersのWebhook利用設定：LINE Developersで本システムのWebhook URLが登録され、「Webhookの利用」が ON になっているか確認してください。
  • 3. LINE公式アカウントの応答設定：LINE Official Account Managerの「設定」＞「応答設定」にて、応答モードが「チャット」または「Bot」、かつWebhookが「ON」になっているかご確認ください。
5

レッスン予約・日程変更カレンダー連携（公式予約URLとリッチメニュー設定）

プロラインやエルメの予約・日程変更カレンダーURLと連携し、受講生がLINE内から1タップで予約を行えるようにします。

  • リッチメニューでの予約設定: リッチメニュー管理エディタ（richmenu.html）のチップ「📅 レッスン予約・日程変更」をクリックすると、受講生個別自動ログイン対応の公式予約URLがセットされます。
  • 受講生マイカルテ（mycar.html）からの連動予約: 受講生マイカルテ画面内の「📅 レッスン予約カレンダーで日時を選ぶ」ボタンを押した場合も、この公式予約URLへ自動直結されます。
6

プロライン・外部ツールの「登録発生時送信」連携（フォーム回答・予約の自動カルテ反映＆スタッフ通知）

プロラインや外部ツール側で受講生がアンケートフォームを送信したり、カレンダーからレッスン予約・日程変更を行った際に、本システムへリアルタイムにデータを送信させ、カルテへの記録とスタッフ通知を即座に連動させる設定です。

設定するWebhook URLの確認方法:
受講生カルテ画面（index.html）またはリッチメニュー画面（richmenu.html）のアカウント設定を開き、
青色枠の「外部システム『登録発生時送信』Webhook URL」をコピーして外部ツールのWebhook送信先へ登録します。
https://あなたのドメイン/proline_webhook.php?account=senior
プロライン / エルメ / LINE Harness 完全共存の仕組み（干渉防止設計）:
プロラインやエルメ、LINE Harness側がメッセージの自動返信（ReplyToken）を行うため、本システム側では受講生からの通常メッセージに対して自動返信を行わず、カルテの記録・最終やり取り日時の同期・個別リッチメニューの適用に専念します。これにより、LINEのReplyToken二重消費エラーを防止し、すべてのシステムが100%干渉せずに共存します。また、複数ツールへの転送は並列非同期通信（curl_multi）でミリ秒処理されるため、通信遅延が一切生じません。

3. LINE受講生一括同期

LINE公式アカウントの全友だち情報を瞬時にカルテ一覧へ同期

LINE公式アカウントの友だちリスト（フォロー中の受講生）を自動取得し、受講生カルテ一覧に一括同期します。

1

ヘッダーの「LINE友だち一括同期」ボタンをクリック

管理画面上部にある緑色の「 LINE友だち一括同期」ボタンを押します。

2

リアルタイム進捗率（パーセント・件数）の可視化

同期中は専用の進捗プログレスダイアログが自動表示されます。
進捗率（0%〜100%）、処理件数（例: 150 / 300名）、新規登録数、情報更新数、および現在同期中の受講生名ストリームがリアルタイムに滑らかにアニメーション更新されます。

3

高速並列通信（curl_multi）＆分割バッチ処理

友だちが何百人・何千人いてもサーバーがタイムアウト（フリーズ）しないよう、15件ずつの分割バッチ処理と並列プロフィール取得を自動実行します。数十秒かかる大量のデータ同期も途切れることなく安全に完了します。

4

同期完了と自動カルテ更新

100%に達すると完了トーストとお祝いメッセージが表示され、最新のアイコン画像・受講生名がカルテ一覧へ自動反映されます。

LINE友だちのブロック・ブロック解除の自動認識

・リアルタイム自動検知: 受講生がLINE公式アカウントをブロック（友だち解除）した瞬間にWebhook（unfollow イベント）を検知し、カルテ上に「🚫 ブロック中」バッジを自動付与して最終やり取りに記録します。再度ブロック解除（follow）された際も自動で「✨ 友だち」状態へ復帰します。
・一括同期でのブロック整合性チェック: 「LINE友だち一括同期」実行時にも、LINE公式アカウントのフォロワー一覧から外れた受講生を自動でブロック中として整合同期します。
・絞り込みフィルター: 管理画面の「友だち中」「🚫 ブロック中」タブでワンクリックで切り替えて一覧表示できます。
・スタッフ通知: ブロック発生時やブロック解除時には、DiscordやSlackへ即座に通知が送信されます。

4. 受講生カルテ・期日管理

受講コース、使用機器、次回レッスン、PC健康診断、会員更新期日の管理

受講生一覧テーブルでは、受講生ごとに必要なアクションを迅速に行えるよう、「4列 × 2行」の整然とした操作ボタングリッドを採用しています。全ボタンの高さ・幅・フォントサイズが統一され、直感的な配色で分かりやすく整理されています。

1

操作ボタングリッドの構成（4列 × 2行）

各受講生行の右端にある「操作」列には、8つの機能が整列配置されています：

  • 【上段1】💬 チャット（緑）: 受講生との1対1トーク履歴の確認、返信、未読バッジの確認
  • 【上段2】🎛️ メニュー（紫）: 次回期日メッセージを帯合成した個別リッチメニューの設定・解除
  • 【上段3】📢 お役立ち / 📋 アンケート（青）: シニア向け役立つ情報やDXアンケートの個別Flex送信
  • 【上段4】✏️ 編集（スレート）: カルテ編集モーダルを開き、受講コースや期日情報を更新
  • 【下段1】💻 レッスン（水色）: 次回レッスン案内のFlexリマインドLINEを送信
  • 【下段2】🔍 PC診断（エメラルド）: 定期PC健康診断案内のFlexリマインドLINEを送信
  • 【下段3】🗓️ 会員更新（橙）: 会員更新・月謝期日案内のFlexリマインドLINEを送信
  • 【下段4】🗑️ 削除（赤）: 受講生レコードの削除（誤登録や重複データの整理）
2

受講コース・使用機器・期日の入力

  • 受講生氏名: 受講生の実名（LINE名とは別に教室管理名として保持）
  • 受講コース名: 【シニア安心】パソコン入門コース、スマホ・タブレット活用コース、Word・Excel実用コースなど
  • 機器/会員番号: Windows 11 ノートPC、iPad Air、会員No.1024 など
  • 次回レッスン予定日: 次回予約している受講日時
  • 定期PC健康診断日: パソコンの動作チェック、空き容量整理、セキュリティ確認の推奨日
  • 会員更新・月謝期日: 月謝のお支払い期日または年次会員更新日
  • カルテメモ: 苦手な操作（文字入力、マウス操作）、受講進捗、特記事項
3

ページネーション（ページ分割表示）と高速検索

  • ページ分割表示: 受講生が1,000名規模に増えてもブラウザが重くならず快適に動作するよう、1ページあたり50件ずつのスマート分割表示を採用しています。
  • 表示件数の切り替え: テーブル下部のセレクターから「25件」「50件」「100件」「全件」をいつでもワンクリックで変更できます。
  • 高速デバウンス検索: 検索ボックスに受講生名やコース名を入力する際、入力確定を自動検知して高速フィルタリングを行い、ブラウザのフリーズを防ぎます。
4

表示カラムの選択（表示・非表示のカスタマイズ）

  • 表示項目の自由切替: ツールバーの「 表示項目」ボタンから、テーブルに表示したい列をチェックボックスでいつでも自由に切り替えられます。
  • 用途に合わせたスリム化: 例えば「チャット対応のみを行いたいときは期日列を隠す」「ノートPCなど画面幅が狭いときはメモ列を隠す」など、状況に応じた最適な表示レイアウトが作れます。
  • 設定の自動保存: 選択した表示設定はブラウザ（localStorage）に自動保存され、次回アクセス時やページ切り替え時も常に維持されます。「初期化」を押すといつでも全表示に戻せます。

🏷️ 属性タグ付け＆一括タグ操作・タグ絞り込み検索機能【新機能】

受講生ごとに「月謝会員」「体験受講」「スマホコース」「シニア初級」「個別指導」などの自由なタグを付与し、受講生の分類・絞り込み検索や、タグ連動リッチメニューの自動出し分けに活用できます。

  • 個別カルテからのタグ設定: 受講生一覧の「✏️ 編集」ボタンからカルテ編集モーダルを開き、「🏷️ 属性タグ」欄にカンマ区切りで入力するか、下部に表示される既存タグ候補（サジェストチップ）をワンクリックして設定・解除できます。保存するとタグ連動リッチメニューも即座に自動判定されます。
  • 一覧テーブルでのタグ表示＆ワンクリック絞り込み: 受講生行の「属性タグ」列に色鮮やかなタグバッジが表示されます。タグバッジをクリックするだけで、そのタグが付いた受講生のみを瞬時に絞り込み表示できます。
  • 上部ドロップダウンでのタグ絞り込み: 検索バー横の「🏷️ 全てのタグ」セレクターから特定のタグを選ぶだけで、該当する受講生を即座にフィルタリングできます。
  • 複数受講生への一括タグ操作（追加・削除・置換）: テーブル左端のチェックボックスで複数名の受講生を選択すると、画面下部に青色の「一括操作ツールバー」がスライド表示されます。「🏷️ 一括タグ操作」ボタンを押すと、選択した受講生全員に対して一括でタグを追加・削除・置き換え（上書き）できます。
  • チャット画面でのタグ確認: 「💬 チャット」モーダルを開いた際も、受講生名の下に設定中の属性タグバッジが表示され、受講生属性を確認しながらスムーズに個別メッセージ対応を行えます。

5. 直近予定日の自動反映機能

次回レッスン・PC健康診断・会員更新のうち最も近い予定を自動判定

1

リアルタイムサマリー表示

日付を入力すると、フォーム下部に「最も期限が近い予定」が自動表示されます。
例: 「 次回レッスン: 2026-10-15 (あと8日)」

「保存と同時に、直近の期限メッセージで専用リッチメニューをLINEに自動適用する」にチェックを入れた状態で保存すると、自動的にメッセージが入った個別メニュー画像が生成され、受講生のLINEメニューが即座に切り替わります。

6. 特定受講生向け個別リッチメニュー設定

受講生のLINE画面に専用メッセージ帯（次回レッスン日等）を焼き込み表示

受講生一覧の「 メニュー設定」ボタンをクリックすると、その受講生専用の設定モーダルが開きます。

A

定型文チップによる簡単入力

「最も近い予定 (あと〇日)」「次回レッスン」「定期PC健康診断」「会員更新」ボタンを押すだけで、最適なメッセージが自動生成されます。「山田様 次回レッスンは10月15日(火)10時からです」など自由な編集も可能です。

B

帯の高さ設定（デフォルト300px・px直接指定）& 自動折り返し・フォント自動縮小調整

・帯の高さ設定（デフォルト標準 300px 固定）:
初期状態で最もバランスの良い「標準 300px」が自動設定されています。スライダーや数値入力（50px〜1000px）、またはクイックチップ（細め180px、標準300px、太め420px、特大550px、極太700px、自動伸縮）で帯の高さを自由に微調整・固定できます。
・自然な自動折り返し（Word Wrap） & 帯枠内への自動フォント縮小（スマートフィット）:
長い文章や大きなフォントサイズを指定しても、横幅を超えたテキストは自然に次行へ折り返されます。さらに行数が増えて帯の高さ（300px等）に収まりきらなくなった場合は、文字が縦長に変形・潰れることなく、枠内にぴったり収まる最適なフォントサイズまで自動で縮小調整されます。
・文字フォントサイズ (20px〜250px): スライダー操作に加え、直接数値入力ボックス（例: 85px、140pxなど）を完備。ワンクリックのサイズチップ（極小40px、標準65px、大90px、特大130px、超特大180px）も備え、極小注記から超特大テロップまで自在に調整可能です。
・文字の上下配置（垂直アライメント）: 中央揃え（標準）、上揃え、下揃えを選択可能。固定した帯の中で文字を好みの位置に美しく配置できます。
・帯の背景色 (HEX) & 文字色 (HEX): カラーピッカーでの直感選択に加え、#ff8700（デフォルト：オレンジ）などの16進数HEXカラーコードを直接手入力可能。定番プリセット（オレンジ・赤・青・緑・ゴールド・黒・紫・ピンク・白）もワンタップで選択できます。
・立体グラデーション効果: チェックを付けると自然な陰影と高級感のある立体グラデーションが自動適用され、外すとフラットな単色で焼き込みされます。
・タップ誘導ガイド表示: チェックを入れると画像上に「👆 タップして開く」の小さな誘導ガイドが焼き込まれます（メッセージをすっきり見せるため初期設定はデフォルトでOFFになっています。必要に応じてONに切り替えてご利用ください）。

C

全体共通メニューへの復帰

「全体共通に戻す」ボタンを押すだけで、いつでも教室共通（プロライン標準）のデフォルトメニューに戻せます。

【重要】プロラインのボタン設定を100%引き継ぐ安心仕様

ベースメニューには「★ [全社公開中]（プロラインの現在メニュー）」が自動選択されます。モーダル内の「 プロラインから同期」ボタンを押すと、LINEサーバーからプロライン最新メニュー（画像とボタン設定）が即座に取り込まれます。
本システムはプロラインが設定したボタン配置・アクションURL・予約設定をそのまま完全継承し、画像上部にメッセージ帯だけを上書き合成して受講生に個別配信するため、プロラインの既存機能（カレンダー予約等）を一切壊すことなく安全に共存できます。

2

ボタン領域（Areas）とお役立ち情報アクションの自由設定

メニュー画像上の各枠（ボタン）をタップした際の動作として、以下を自由に選択・配置できます：

  • 💡 お役立ちガイド一覧: タップするとトーク画面下部に横スクロール式クイックリプライが表示され、全11テーマを自由に閲覧できます。

「プロラインからメニュー同期」機能

画面右上の「 プロラインからメニュー同期」ボタンを押すと、LINE公式アカウント（プロライン）に現在公開されている最新メニューの「画像」と「ボタン設定（タップ領域・アクションURL）」をLINEサーバーから自動取得して本システムに取り込みます。
プロライン側でメニュー画像やボタン配置を更新した際、この同期ボタンを押すだけで最新デザインとボタン設定が本システムに即時反映されます。

3

登録・履歴一覧とスマートページネーション

「登録・履歴一覧」タブでは、作成・保存した過去のリッチメニューを一覧管理できます。
メニュー数が増加した場合でも快適にブラウジングできるよう、スマートページネーション機能（6件 / 9件 / 18件 / 全件表示切り替え）を搭載しています。「すべて」「通常メニュー」「お知らせ専用メニュー」のフィルタータブとも連動し、ページめくりも高速・軽快に動作します。

🎯 タグ連動リッチメニュー出し分け＆一括同期機能【新機能】

リッチメニューごとに「出し分け対象タグ」を設定することで、特定のタグが付いた受講生のLINE画面にのみ指定のリッチメニューを自動表示（出し分け）できます。

  • リッチメニューでの対象タグ設定: エディタ画面の基本設定内「🏷️ 出し分け対象タグ」欄に、表示対象としたいタグ（例: 月謝会員 や スマホコース）を入力するか、既存タグ候補チップをクリックして指定します。空欄の場合は誰でも表示可能な「通常メニュー（全体デフォルト）」となります。
  • リアルタイム自動反映: 受講生カルテでタグを付与・変更・保存した瞬間に、該当受講生が保有するタグと合致するリッチメニューがLINE Messaging API経由で自動適用（lineLinkUserRichMenu）されます。
  • 🏷️ タグ連動メニューを一括同期: 「登録・履歴一覧」タブのツールバーにある「🏷️ タグ連動メニューを一括同期」ボタンを押すと、全受講生の属性タグを再スキャンし、各受講生に最適なタグ連動メニューを全友だちのLINEへ一括反映（同期）します。
  • 履歴一覧でのタグバッジ表示＆絞り込み: 履歴一覧カードには紫色のタグバッジが表示され、フィルタータブの「🏷️ タグ連動」を押すことで、タグ設定されたメニューのみを素早く絞り込めます。
  • 専用メッセージ帯との安全な共存設計: 次回レッスン日などの「専用メッセージ帯」が個別設定されている受講生は専用メッセージが最優先保持され、タグ自動切り替えで上書きされないよう二重ガードされています。

🧹 リッチメニュー初期化（リセット）機能【新規アカウント作成時・完全クリーン化】

新規で他社アカウントや新店舗アカウントを作成した際、またはメニュー構成を一新してまっさらな初期状態からスタートしたい場合、画面上部ビュースイッチャーバーの「 リッチメニュー初期化」ボタンから初期化を実行できます。
初期化を実行すると以下が安全に実施されます：

  • 現在選択中のアカウントの登録リッチメニューを全消去（DBテーブル rich_menus を初期化）
  • LINE公式アカウント（Messaging API）上のデフォルトリッチメニュー解除＆メニュー・エイリアス削除（チェックを入れた場合）
  • 個別受講生に割り当てられていたカスタムメニューの解除（全体デフォルト状態へ統一）
  • エディタの全入力欄・プレビューをまっさらな初期状態へクリア
アカウント完全分離の安心安全設計:
初期化処理は「現在ヘッダーで選択しているアカウント」のみを対象として実行されます。別のアカウント（例: シニア教室など）に登録されているリッチメニューやLINE設定には一切影響しませんので、安心してお使いいただけます。

受講生側のLINEトーク画面では、以下のように視覚的・操作的に最高に探しやすい設計となっています：
1. 全20テーマの2連カルーセル一覧：リッチメニューやお役立ちカードの「その他のお役立ち情報」を押すと、🚨防犯・トラブル対策編（10選）と📱💻スマホ・PC快適便利ワザ編（10選）の2通の横スクロールカルーセルが届き、見出し・要点2点・「詳しく読む」ボタンを見比べながらスムーズに探せます。

3. 自動応答キーワード：受講生がトーク画面で「お役立ち」「豆知識」「PDF」「パソコン」「スマホ」などと入力した場合も、自動的にお役立ち案内が返信されます。

🎠 横スワイプで見渡せる「2連カルーセル一覧表示」機能:
「📚 全20テーマ一覧」ボタンを押した際や「お役立ち」と送信した際は、🚨 防犯・トラブル対策編（10選）と📱💻 スマホ・PC快適便利ワザ編（10選）の2連カルーセルで届きます。LINEのカルーセル上限（1通12バブル）を美しくカテゴリ分割してクリアし、シニアの方でも指で左右にスワイプしながら各テーマのポイント要約を見比べ、「📖 詳しく読む」ボタンから瞬時に大文字解説カードを開くことができます。
🔇 管理者側通知音を防止するサイレント設計:
クイックリプライボタンやカルーセル内の「詳しく読む」ボタンは、タップしても受講生がトーク画面で発言（テキスト送信）した扱いにならないサイレントPostback（裏側通信）仕様となっています。そのため、受講生が記事をどんどん読んでも管理者にピコンと着信通知音が鳴り続ける心配はありません。
🌟 応答後も消えない「常時表示」安心仕様:
LINEの標準仕様では新しいメッセージを受信するとクイックリプライが消えてしまいますが、本システムではボットからのすべての返信応答（質問受付、カルテ案内、お役立ちカード等）の末尾にクイックリプライを自動補完・再生成しています。そのため、受講生が何通やり取りしてもボタンが消えず、常に画面最下部から次のテーマをワンタップで読み進められます。

シニアパソコン教室・アップファーレン店舗など、複数アカウントを1つの管理システムで統合運用

1

ヘッダーの「アカウント切替」からワンクリックで切り替え

管理画面（受講生カルテ）、リッチメニュー管理、操作マニュアルの画面上部ヘッダーに配置された「アカウント切替」ドロップダウンから、操作対象のLINE公式アカウント（例: シニア向けパソコン教室、アップファーレン等）をいつでも瞬時に切り替えることができます。
切り替えると、顧客一覧・リッチメニュー・店舗ロゴ・タイトルバッジが連動してそのアカウント専用のものに自動更新されます。選択したアカウントはブラウザに自動記憶され、次回ログイン時も直近のアカウントが維持されます。

💡 画面リロード不要のスマート同期:
アカウントを切り替えると、ページ全体を再読み込みすることなく、内部通信が自動的に対象アカウントへ切り替わり、該当アカウントの最新データが即時再読み込みされます。
2

データベース（DB）完全分離による安全設計

本システムは、アカウントごとに専用のSQLiteデータベースファイル（例: kureba-senior-system.db、kureba_kaisya_dx.db など）を完全に分離して管理しています。
これにより、顧客カルテや受講履歴、作成したリッチメニュー、配信履歴などが別のアカウントと混ざってしまう危険（データの交差汚染）を根本から防止しています。

アカウントごとのリッチメニュー完全独立 & クリーンスタート

各LINE公式アカウントのリッチメニュー（作成データ、本番公開メニュー、LINEサーバー上のメニューID・エイリアス、受講生ごとの個別メニュー設定）も、アカウントごとに完全独立したデータベースおよびLINEチャネルアクセストークンで管理されます。
新しく追加したアカウントのリッチメニュー管理画面を開いた際、前のアカウントのメニューが混ざることはありません。また、「🧹 リッチメニュー初期化」ボタンを使うことで、いつでも完全な初期状態（未登録・クリーン）からアカウント専用のメニュー構築をスタートできます。

12. 個別LINEチャット・メッセージ返信

受講生との1対1トーク履歴確認・直接Pushメッセージ返信機能の使い方

受講生からLINE公式アカウントへ届いたメッセージを管理画面上でリアルタイムに閲覧し、スタッフから受講生のLINEトーク画面へ直接返信メッセージを送信できる機能です。
プロラインの自動応答やステップ配信と一切競合せず、管理画面からいつでもスムーズな受講生サポートが可能です。

1

新着メッセージの確認と未読バッジ

受講生からメッセージが届くと、受講生一覧テーブルの受講生名横および「💬 チャット」ボタンに赤色の未読バッジ（件数）が表示されます。
「最終やり取り」カラムにもメッセージ内容のプレビューと受信日時が自動反映されます。

2

チャット画面の起動と会話履歴の確認（画像・メディア完全対応）

対象受講生の行にある「💬 チャット」ボタンをクリックすると、LINE風のチャットモーダルが開きます。
・受講生のメッセージは左側（白吹き出し）、スタッフからの返信は右側（緑吹き出し）に時系列で表示されます。
・📷 画像・写真メッセージ：受講生から送信された写真やスクリーンショットは、LINE APIより自動ダウンロードされてチャット内にサムネイル表示されます。画像をクリックすると新しいタブで原寸大の鮮明な写真を確認・保存できます。
・🎬 動画 / 🎵 音声 / 😊 スタンプ：各種メディアもチャット画面上で直接再生・確認できます。
・チャット画面を開いた時点で未読フラグは自動的に既読として処理されます。
・チャットモーダルを開いている間は10秒ごとに自動更新（ポーリング）され、受講生からの最新メッセージが即座に反映されます。

3

メッセージの送信とクイック定型文

画面下のテキストエリアにメッセージを入力し、紙飛行機ボタンをクリックするか、キーボードの Ctrl + Enter（Macは Cmd + Enter）を押すと受講生のLINEトーク画面へプッシュ送信されます。
便利な定型文チップ（「挨拶」「確認中」「予約確認」「フォロー」）をクリックすると、ワンタップでよく使う返信文面を入力欄に自動挿入できます。

4

連携画像受信時のマルチ通知（管理者LINE・Discord・Slack）

受講生から画像のみが送信された場合でも、システムが自動的に画像メッセージ（📷 画像を受信しました）として検知し、スタッフへ即座に通知します。

  • 管理者LINE通知: 送信者名・受信日時に加え、画像の直通URLおよび画像メッセージが管理者のLINEへ即座にプッシュ配信されます。
  • Discord通知: Discord通知メッセージ内に受信画像が埋め込み（Embed Image）表示され、Discord上で瞬時に写真の内容を確認できます。
  • Slack通知: 受信メッセージ内容とともに画像が通知され、管理画面への直通リンクから1クリックで返信できます。
5

NEW送信者名（担当者名）の指定と「from」の非表示対応

チャット入力欄の上部にある「 送信者名」欄により、受講生のLINE画面での送信者名（Sender）表示を柔軟にコントロールできます。

  • 1. 空欄または「🚫 なし」チップ（from非表示・公式アカウント名そのまま）: 送信者名を空欄にするか「🚫 なし (from非表示)」チップを押すと、「from ~~~」という表示を一切出さず、通常のLINE公式アカウントからのすっきりとした吹き出しとして送信されます。
  • 2. 名前を入力（「川合」「教室スタッフ」など）: 入力した担当者名がLINEアプリ上の吹き出しに「from 川合」として小さく表示されます。クイックチップ（「川合」「教室スタッフ」「サポート担当」）を押すだけでワンタッチ入力も可能です。
  • 3. 前回の送信者名を自動記憶（localStorage）: 設定した送信者名はブラウザに自動保存され、次回チャットを開いた際も前回の設定がそのまま維持されます。
  • 4. 管理画面チャット履歴への記録: 管理画面の吹き出し下部にも送信担当者名が記録・表示され、スタッフ間で誰が返信対応を行ったかが一目で把握できます。
6

NEWPCブラウザ通知（デスクトップポップアップ＆チャイム音通知）

管理画面を開いていれば、別タブで作業中やウィンドウを最小化している場合でも、受講生からのLINE新着メッセージを瞬時に見逃さずキャッチできます。

  • 1. ブラウザ通知の有効化: ヘッダーツールバーの「 ブラウザ通知: OFF」ボタンをクリックし、ブラウザのポップアップで「許可」を選択すると有効（ON）になります。
  • 2. デスクトップポップアップ通知: 受講生からメッセージが届くと、PC画面の右下（Macは右上）に受講生名・写真・メッセージ本文のプレビューがデスクトップ通知として即座にポップアップします。
  • 3. 心地よいチャイム音再生: 新着検知時にクリアで優しいベル音（ポロン♪）が自動再生され、画面を見ていない時でも受信に気づけます。
  • 4. 通知クリックでチャット直通起動: 届いたデスクトップ通知をクリックすると、ブラウザが前面に表示され、該当受講生とのチャット画面が自動的に開いて即座に返信できます。
プロライン共存の仕組み
本機能は、LINE Messaging APIのPush Messageを使用しています。受講生からのメッセージ受信時にもReplyTokenを消費しないため、プロラインの自動返信・ステップ配信・予約シナリオの動作を一切妨げません。

15. 会社DX 関心度アンケート配信・自動ヒアリング機能

LINEトーク画面上でワンタップ回答できる対話式アンケートと自動カルテ連携

1

機能の概要と目的

「会社DX」アカウントのLINE友だちに対し、企業のDX（デジタル化・業務効率化）への関心度や、具体的に興味のある分野を2ステップで手軽にヒアリングできる対話式アンケート機能です。LINEのリッチカード（Flex Message）を活用し、友だちが画面上の選択肢をタップするだけで回答が完了します。

2

2ステップ対話アンケートの流れ（自動応答）

友だちのLINEトーク画面上で以下のようにスムーズに進行します：

  • 【Q1: DX関心度】: 「🔥 大いにある（すぐにでも取り組みたい）」「💡 少しある（情報収集中・事例を知りたい）」「☕ 今はまだない（状況を見守り中）」の3択から選択。
  • 【Q2: 関心のあるテーマ・課題】: Q1で「大いにある」または「少しある」と答えた友だちに自動で表示。「💻 ペーパーレス化」「🤖 生成AI社内活用」「📱 LINE集客自動化」「📊 クラウド一元管理」「🤝 無料相談・他社事例」「✏️ その他」の中から興味のあるテーマをタップ。
3

管理画面からの配信手順（一斉配信 / 個別送信）

  1. 画面上部のアカウント切り替えで「会社DX」を選択します。
  2. ヘッダーの「📋 DXアンケート配信」ボタンをクリックすると配信スタジオが起動します。
  3. 「友だち全員に一斉配信」または「特定の顧客・担当者に個別送信」を選択します。顧客一覧の各行にある「📋 DXアンケート」ボタンから直接個別指定して送信することも可能です。
  4. 「このアンケートをLINE配信する」をクリックすると、確認ダイアログののち即座に対象者のトーク画面へFlex Messageが送信されます。
4

回答結果の自動保存・即時通知

  • カルテ自動保存: 回答された内容は、顧客カルテのメモ欄（staff_memo）および最新やり取り（last_interaction）に「【会社DXアンケート回答】関心度: 大いにある / 関心テーマ: 生成AI社内活用」として自動追記・タイムスタンプ保存されます。
  • 一覧テーブルでの回答済バッジ: アンケート回答済みの顧客には、一覧のメモ列に青い「📋 DXアンケート回答済」バッジが表示され、ひと目で未回答・回答済を判別できます。
  • 管理者LINE & Discord & Slack速報通知: 友だちが回答した瞬間に、管理者の個人LINE、DiscordおよびSlackへ「🏢 会社DX アンケート回答速報」が即時プッシュ通知されます。熱度の高い見込み客に対して即座に個別チャット等でアプローチできます。
キーワード自動応答にも対応
友だちがトーク画面で「アンケート」「dxアンケート」「DX相談」「効率化」などと入力した際にも、システムが自動的にこのQ1アンケートカードを返信します。配信を受け取っていなくても、興味を持った顧客がいつでも能動的にアンケートを回答できます。

・ログイン状態の維持：認証に成功すると、ブラウザにセキュアな認証トークンが保持され、同一ブラウザで30日間安全に操作を継続できます。右上のログアウトボタンを押すことで即座に認証を取り消せます。

3

画面上からの設定変更＆テスト送信（新機能）

管理画面ヘッダーの「 2FAセキュリティ」ボタンをクリックすると、設定モーダルが開きます：
・二段階認証の有効化/無効化：スイッチ一つでいつでもON/OFFを切り替え可能。
・送信先メールアドレスの変更：ご担当者様のメールアドレスを画面上で直接更新可能。
・コード有効期限・最大試行回数の設定：5分〜30分、3回〜10回まで柔軟に設定可能。
・🧪 テスト認証メール送信：現在の設定でテストメールが届くかをワンクリックで事前確認できます。
※直接ファイルで設定したい場合は public_html/config.php 内の ENABLE_ADMIN_2FA や ADMIN_2FA_EMAIL を編集することも可能です。

ワンポイントTips: 全画面での認証共有＆安心のテスト機能
・カルテ管理画面（index.html）、リッチメニュー管理（richmenu.html）、操作マニュアル（manual.html）のいずれかで一度二段階認証を完了すると、同一ブラウザ内であれば別画面へ移動した際も自動的に認証が引き継がれます。

18. 他社・別レンタルサーバー移行＆初期セットアップ

自社レンタルサーバーへの導入手順・環境診断ウィザード・個人情報ゼロのクリーンセットアップ

本システムを他社やクライアントのレンタルサーバー（エックスサーバー、ロリポップ！、さくらインターネット、ConoHa WING等）へ新規導入・移行する際の手順です。
配布用パッケージには過去の顧客データやチャット履歴が一切含まれておらず、ブラウザから setup.php を開くだけでサーバー要件の自動診断と初期設定が完了します。

1

レンタルサーバーへファイルをアップロード

FTPソフト（FileZilla等）またはサーバー管理画面のファイルマネージャーを使い、公開フォルダ（public_html 等）にZIPを解凍してアップロードします。
以下のフォルダに書き込み権限（パーミッション 755 または 777）が付与されていることを確認します：
・public_html/data/（アカウント情報保存）
・public_html/uploads/（リッチメニュー画像保存）
・batch/（定期リマインドバッチおよびSQLiteデータベース保存）

2

ブラウザで環境診断＆セットアップウィザードを実行

ブラウザで https://あなたのドメイン/setup.php にアクセスします：
1. サーバー環境診断: PHP 8.0以上、PDO SQLite、cURL、GD、mbstring、フォルダ権限が自動検証され、すべて緑色の「正常 (OK)」が表示されます。
2. アカウント情報入力: 店舗名・教室名、LINE Messaging API チャネルアクセストークン（長期）、チャネルシークレット、LIFF ID、管理者ログインパスワードを入力します。
3. LINE API 疎通テスト: 「LINE API 疎通テスト」ボタンを押し、公式アカウント名が正しく取得できることを確認します。
4. 初期化実行: 「設定を保存してシステムを初期化する」を押すと、SQLiteデータベースと全テーブルがクリーンな状態で自動生成されます。

3

LINE Developers での Webhook URL 設定

LINE Developers コンソール を開き、Messaging API設定の「Webhook URL」に以下を登録します：
https://あなたのドメイン/webhook.php
「検証」ボタンを押して「成功」を確認後、「Webhookの利用」を オン（有効） に設定します。

4

毎朝の定期リマインドCron設定

サーバーのCRON管理画面に、毎日朝8:00実行（0 8 * * *）としてバッチスクリプトを登録します：
/usr/bin/php /home/あなたのサーバーID/ドメイン名/batch/reminder.php
これにより、次回レッスン・PC健康診断・会員更新のリマインドLINEが毎朝自動プッシュ配信されます。

既存データの完全非含有仕様:
当システムはSQLite3（ファイル型DB）を採用しているため、MySQLの作成やSQLのインポートは一切不要です。初期配布パッケージには過去のお友達データやチャット履歴は一切含まれず、他社へ安心してシステムを提供できます。

22. よくある質問・トラブルシューティング

困ったときの解決方法

Q

クイックリプライをオフにしたのに、受講生・顧客のLINE画面からボタンが消えない場合は？

LINEアプリの仕様：クイックリプライは、端末側に届いた「直近のメッセージ」に紐づいて画面下部に表示されます。
クイックリプライを「表示しない（完全無効化）」に設定後、一度個別チャットまたはプッシュ配信（テスト配信など）を送信してください。クイックリプライ無しの新しいメッセージが届いた時点で、LINE画面下部の丸ボタンは完全に消去されます。

Q

他社アカウントを作成した際、パソコン教室用のクイックリプライが出ないようにするには？

本システムでは、senior 以外のすべてのアカウントにおいて、初期状態でクイックリプライが完全無効（オフ）に設定されています。ヘッダーの「⚡ クイックリプライ」から必要に応じて「汎用ビジネス」や「自由カスタム」に切り替えてご利用いただけます。

Q

二段階認証のメールが届かない場合は？

以下の点をご確認ください：
1. 迷惑メールフォルダの確認：お使いのメールソフトの「迷惑メール」「プロモーション」「ゴミ箱」フォルダに振り分けられていないかご確認ください（件名: 【シニア向けパソコン教室】管理画面ログイン認証コード）。
2. コード再送信の利用：画面上の「コード再送信」ボタン（60秒経過後に有効化）を押して再送信をお試しください。
3. サーバーのメール送信（sendmail / PHP mail）環境：サーバー側のメール送信制限やSPF/DKIM設定の影響を受けていないかご確認ください。

Q

リッチメニューに設定する「予約」と「マイカルテ」のURLは何を指定すれば良いですか？

リッチメニュー管理エディタ（richmenu.html）のチップからワンクリックで設定できます：
・レッスン予約・日程変更ボタン: https://liff.line.me/2000276344-XlmvL9qZ?r=https%3A%2F%2Fd0o2pa7q.autosns.app%2Fcl%2FQaOK41fkzp%3Fuid%3D%5B%5Buid%5D%5D%26openExternalBrowser%3D1（チップ「📅 レッスン予約・日程変更」をクリック）
・マイカルテボタン: https://liff.line.me/2000276344-YL1wXh0h（チップ「💻 受講生マイカルテ・相談」をクリック）
この2つのURLを設定するだけで、受講生個別の予約・日程変更カレンダーと本システムの受講生マイカルテの両方がLINE上で完璧に動作します。

Q

プロライン側でメッセージが届かない、またはステップ配信が動かない時は？

以下の3点をご確認ください：
1. 管理画面右上の「プロライン連携」モーダルを開き、「プロライン転送を有効にする」にチェックが入っているか確認してください。
2. 「疎通テスト送信」を実行し、HTTPステータス200が返るか確認してください。
3. ブラウザで https://あなたのドメイン/webhook.php を開き、プロライン転送ログを確認してください（転送失敗時はエラーコードが表示されます）。

Q

プロラインと本システムで自動返信が競合することはありませんか？

競合しません。本システムの「プロライン転送」が有効な場合、受講生からのテキストメッセージに対する自動応答（ReplyTokenの消費）は完全に抑止され、プロライン側へ委ねられます。本システム側はカルテへの同期とプッシュ配信・リッチメニュー表示のみを行います。

Q

メニュー設定を変更したのに受講生のLINE画面が変わりません

LINEアプリの仕様上、トーク画面を開いたままの場合は画像キャッシュが残ることがあります。一度別のトーク画面やホーム画面に戻ってから、再度教室の公式アカウントトーク画面を開き直すと最新のメニューに即時更新されます。

Q

お役立ち情報配信で「送信失敗」と表示される場合はどうすればいいですか？

以下の点をご確認ください：
1. LINE公式アカウントの月間配信通数上限：LINE公式アカウント（無料プラン等）で月間の無料メッセージ通数枠（例: 月200通など）を超過している場合、LINEサーバーから配信制限エラーが返されます。その場合はLINE Official Account Managerより配信可能残数をご確認ください。
2. LINE未連携の受講生への個別送信：手動登録などでLINEと未連携（UIDがMANUAL_から始まる）の受講生には個別プッシュ送信ができません。「LINE友だち全員へ一斉配信」を利用するか、受講生に友だち登録およびマイカルテ連携をご案内ください。
3. エラー詳細の確認：送信失敗時には、LINEサーバーから返された具体的なエラー内容がダイアログに明示されます。内容をご確認のうえご対応ください。

Q

受講生からチャットで画像だけが届いた場合、通知や管理画面への反映はどうなりますか？

・リアルタイム通知：受講生からテキストがなく画像のみが届いた場合でも、システムが自動的に画像メッセージ（📷 画像を受信しました）として検知し、管理者LINE通知・Discord通知・Slack通知が即座に送信されます（Discord通知では画像自体がリッチ表示されます）。
・画像データの自動保存と高解像度プレビュー：LINE Messaging APIから画像データがサーバーへ自動保存され、管理画面のチャットモーダルにサムネイルが表示されます。クリックすると別タブで原寸大の鮮明な写真を確認・保存できます。

Q

PCブラウザ通知が届かない、または音が鳴らない場合は？

1. ブラウザの通知許可確認：管理画面上部の「ブラウザ通知」ボタンが「ON」になっているかご確認ください。もしブラウザ側で通知がブロックされている場合は、アドレスバー左側の鍵アイコン（サイトの設定）をクリックし、通知を「許可」に変更してください。
2. 音声再生のブラウザ自動再生制限：ChromeやEdge等のブラウザ仕様により、ページを開いてから一度も画面をクリックしていない状態では自動音声再生が制限される場合があります。管理画面の任意の場所を一度クリックして操作を開始してください。
3. OS側の通知設定（Windows / Mac）：Windowsの「集中モード / 応答不可」やMacの「おやすみモード」が有効になっていると、デスクトップ通知が非表示になることがあります。OSの通知設定をご確認ください。

Q

友だち（受講生）からのLINEチャットが管理画面に届かない・反映されない場合は？

以下の3つのチェックポイントを順にご確認ください：
1. LINE Official Account Manager（管理画面）の応答設定：
・管理画面（manager.line.biz）の「設定（歯車マーク）」＞「応答設定」を開きます。
・「応答モード」が「Bot」になっているか確認してください（「チャット」になっているとLINE社側でWebhook送信が遮断されます）。
・「詳細設定」の「Webhook」が「オン」になっていることを確認してください。
・「あいさつメッセージ」や「自動応答メッセージ」は必要に応じてオフにしておくと二重返信を防げます。
2. LINE Developers コンソールの Webhook URL 設定：
・LINE Developers（developers.line.biz）の該当チャネルの「Messaging API」タブを開きます。
・「Webhook URL」に https://あなたのドメイン/webhook.php（マルチアカウント時は ?account=アカウントID）が登録されているか確認します。
・「Webhookの利用（Use webhook）」トグルがON（緑色）になっているか確認し、「検証（Verify）」ボタンで「Success」が出るか確認します。
3. プロライン連携や外部中継ツールとの併用：
・プロライン等を併用している場合でも、本システムは受信と同時にミリ秒単位で最優先にローカルDB保存・未読カウント更新・マルチ通知（LINE/Discord/Slack/ブラウザPush）を行い、その後にプロラインへ完全並列転送します。
・そのため、外部ツールの接続遅延やタイムアウトが発生しても、本システム側でチャットメッセージが消失することはありません。

Q

Q

管理画面のパスワードログインができない・エラーになる場合は？

以下の点をご確認ください：
1. 管理者パスワードの入力確認：デフォルトパスワードは 1020143 に設定されています（変更は public_html/config.php の ADMIN_PASSWORD で行えます）。前後に余分なスペースが入っていないかご確認ください。
2. サーバーのHTTPヘッダー転送環境：当システムはXserverなどの共有ホスティング環境（Apache + FastCGI / PHP-FPM）に対応するため、.htaccess によるヘッダー転送、Bearerトークン、URLパラメータ、セッションCookieによる多重認証に対応しています。最新のコードがサーバーに反映されていることをご確認ください。
3. ブラウザのCookie・ストレージ設定：ログイン状態の保持のためブラウザのCookieおよびセッションストレージ（sessionStorage）を使用します。シークレットモードやCookieブロック設定を行っている場合は許可してください。

Q

管理画面の角丸（デザインシステム）や画面幅はどのように設計されていますか？

画面幅のフルワイド表示：受講生カルテテーブルや統計情報、リッチメニュー管理をストレスなく一覧できるよう、左右の余白（1200px制限）を撤廃し、画面幅いっぱい（100%フルワイド）に広がるモダンレイアウトを採用しています。ワイドモニターでも情報を広々と快適に操作できます。
角丸トークン（デザインシステム）：CSSデザインシステムトークン（--radius-xs: 4px, --radius-sm: 8px, --radius-md: 12px, --radius-lg: 16px, --radius-xl: 20px, --radius-full: 9999px）を全画面（受講生カルテ、個別チャット、Discord設定、リッチメニュー作成、操作マニュアル）に完全標準化し、統一感ある美しいUIを提供します。

Q

受講生数が1,000名近くなっても管理画面が重く・フリーズしない理由は？

スマートページネーション & イベント委譲：大量の受講生データ（900名超）を一括で描画するとブラウザのメモリやCPUを圧迫するため、当システムでは1ページあたり50件に分割描画するページネーションを搭載しています。また、ボタンごとの個別イベントバインドを廃止し、テーブル親コンテナでのイベント委譲処理を行うことで、極めて軽快な動作を実現しています。
検索デバウンス処理：検索ボックス入力時に過剰な再描画が発生しないよう、キー入力のタイピング完了を自動待機（250ms）してから絞り込みを実行するため、日本語入力中でもスムーズに検索できます。

Q

URLから「/public_html/」を外して運用するには？

1. レンタルサーバー公開ディレクトリへの配置（推奨）：エックスサーバーやロリポップ！等の公開フォルダ（public_html/ や htdocs/）の「中身」に、パッケージの public_html/ フォルダ内の各ファイル・フォルダ（admin/, liff/, webhook.php, setup.php 等）を直接配置します。これにより https://あなたのドメイン/admin/ や https://あなたのドメイン/setup.php で直接アクセスできます。
2. ルート .htaccess による自動消去・内部転送：プロジェクトフォルダごと丸ごとアップロードした場合でも、同梱のルート .htaccess により、/public_html/ 付きのアクセスは自動的に / へ301リダイレクトされ、URLから /public_html/ が完全自動消去されます。
