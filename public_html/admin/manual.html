1. システム全体概要

シニア向けパソコン教室向けLINE管理システムの目的と構成

当システムは、シニア向けパソコン教室において、受講生とのコミュニケーション向上、レッスンの無断欠席防止、定期的なパソコン・スマホのメンテナンス受診促進を実現するための専用管理システムです。
既存の「プロラインフリー（ProLine Free）」で構築されたLINE公式アカウント環境を壊すことなく共存できる設計となっています。

A

受講生・カルテ管理画面 (index.html)

受講生一覧、受講コース（パソコン入門、スマホ活用、Word/Excelなど）、使用機器（Windows11、iPad等）、次回レッスン日・定期PC健康診断日・会員更新（月謝）期日の管理とリマインド配信を行います。

B

プロラインWebhook中継プロキシ (webhook.php)

LINE公式アカウントから届くWebhookイベントを本システムで瞬時に受講生カルテに同期した上で、署名ヘッダー付きでプロラインへ完全転送します。プロライン側のステップ配信・シナリオ機能に一切支障を与えません。

C

受講生向け マイカルテ & 予約画面 (LIFF / liff/mycar.html)

受講生がLINEのメニューからワンタップで開き、自分の受講コース、次回レッスン日時、PC健康診断の予定確認、受講予約やお困りごとの個別LINE相談ができます。

2. プロライン＆外部ツール連携（マルチWebhook中継・共存運用）

プロラインのチャット通知・ステップ配信と本システムのカルテ・予約を完全に共存させる設定手順

LINE公式アカウントの仕様上、LINE Developersコンソールに登録できるWebhook URLは1アカウントにつき1箇所しかありません。
そのため、LINE Developersで本システムのWebhook URLを登録するとプロライン側にWebhookが届かなくなり、「プロラインでチャット通知が来なくなる」「ステップ配信が動かなくなる」という問題が発生します。
当システムでは、受信したLINEの全メッセージ・友だち追加イベントを【プロライン】や【その他外部ツール】へリアルタイムに並列同時転送（マルチWebhookプロキシ中継）することで、プロラインのチャット通知やステップ配信を生かしたまま完全共存を実現します。

【メッセージ・イベントのリアルタイム並列中継フロー】
受講生のLINE ➡ [LINE公式アカウント]
  ⬇ (LINE Messaging API Webhook)
[本システム: webhook.php] ➡ 受講生情報・最終やり取り日時をカルテに自動同期＆Slack/Discord通知
  ⬇ (並列非同期curl_multi転送 / 署名X-Line-Signature完全再現)
├➡ [プロライン: autosns.pro/...] ➡ チャット受信通知・ステップ配信・個別返信がそのまま稼働！
└➡ [その他外部ツール: Zapier / Make / Lステップ / エルメ等] ➡ 複数URLへも同時にリアルタイム配信！
1

管理画面でプロライン（および外部ツール）のWebhook URLを登録

管理画面ヘッダー上部の「 プロライン連携」ボタンをクリックして設定モーダルを開きます。

  • 外部ツールへのWebhook自動中継（同時転送）を有効にする: チェックを入れる（ON）。
  • 転送先 Webhook URL: プロライン管理画面で案内されるWebhook URL（例: https://autosns.pro/api/webhook/...）を入力します。
    ※ 複数ツールの登録に対応：Zapier、Make、Lステップ、エルメ、自社サーバー等のURLも1行に1つずつ改行して入力することで、すべてのツールへ同時に中継転送されます。
  • 「 設定を保存する」ボタンを押します。
2

LINE DevelopersコンソールのWebhook URLを本システムに設定

LINE Developersコンソール にログインし、該当チャネルの「Messaging API設定」タブを開きます。

  • Webhook URL に本システムのURL（例: https://あなたのドメイン/webhook.php）を入力し「更新」を押します。
  • 「Webhookの利用」を「有効（ON）」にします。
  • 「検証」ボタンを押し、「成功」と表示されることを確認します。
3

疎通テストの実行

本システムの設定モーダル内にある「 疎通テスト実行」ボタンを押します。
本システムから登録されたすべてのWebhook URLへダミーの署名付きWebhookリクエストが並列送信され、各URLの応答ステータス（OK (200) や所要時間ms）が一覧表示されます。

4

プロラインでチャット通知が来ない場合の確認チェックリスト

  • 1. プロライン Webhook URLの登録確認：本システムの管理画面「プロライン連携」を開き、プロライン管理画面（「初期設定」や「LINE公式アカウント連携」）で案内されるWebhook URL（例: https://autosns.pro/api/webhook/...）が正しく貼り付けられ、「設定を保存する」が完了しているか確認してください。
  • 2. 「疎通テスト実行」でOKが出るか：設定モーダルの「疎通テスト実行」ボタンを押し、OK (200) が返るか確認してください。もしエラーが出る場合はURLに余分な空白や改行が含まれていないかご確認ください。
  • 3. LINE DevelopersのWebhook利用設定：LINE Developers の「Messaging API設定」で、Webhook URLに本システムのURL（https://あなたのドメイン/webhook.php）が登録され、「Webhookの利用」が ON になっているか確認してください。
  • 4. プロライン側の通知設定：プロライン管理画面の「チャット設定」または「通知設定」にて、通知用LINEアカウントまたはメールアドレスへの「チャット受信時の通知」がONになっているかご確認ください。
  • 5. LINE公式アカウントの応答設定：LINE Official Account Manager（LINEヤフー公式管理画面）の「設定」＞「応答設定」にて、応答モードが「チャット」または「Bot」、かつWebhookが「ON」になっているかご確認ください。
5

レッスン予約・日程変更カレンダー連携（公式予約URLとリッチメニュー設定）

レッスンの予約・日程変更URL（https://liff.line.me/2000276344-XlmvL9qZ?r=https%3A%2F%2Fd0o2pa7q.autosns.app%2Fcl%2FQaOK41fkzp%3Fuid%3D%5B%5Buid%5D%5D%26openExternalBrowser%3D1）と連携し、受講生がLINE内から1タップで受講生個別の予約や日程変更を行えるようにします。

  • リッチメニューでの予約設定:
    リッチメニュー管理エディタ（richmenu.html）のチップ「📅 レッスン予約・日程変更」をクリックすると、受講生個別自動ログイン対応の公式予約URLがセットされます。
    受講生がタップすると、LINE UID（[[uid]]）が自動認識され、名前の再入力不要でカレンダー予約・日程変更画面が立ち上がります。
  • 個別メニューのメッセージ帯タップ連動:
    受講生カルテ画面の「個別リッチメニュー設定」で「📅 レッスン予約・日程変更を開く」を指定すると、次回レッスン日のメッセージ帯をタップした際にもこの予約カレンダーが自動起動します。
  • 受講生マイカルテ（mycar.html）からの連動予約:
    受講生マイカルテ画面内の「📅 レッスン予約カレンダーで日時を選ぶ」ボタンを押した場合も、この公式予約URLへ自動直結されます。
6

NEWプロライン「登録発生時に外部システムにデータを送信する」連携（フォーム回答・レッスン予約の自動カルテ反映＆スタッフ通知）

プロライン側で受講生がアンケートフォームを送信したり、カレンダーからレッスン予約・日程変更を行った際に、本システムへリアルタイムにWebhookデータを自動送信させ、カルテへの記録とスタッフ通知を即座に連動させる設定です。

設定するWebhook URLの確認方法:
受講生カルテ画面（index.html）またはリッチメニュー画面（richmenu.html）のヘッダーにあるアカウント名「⚙️ アカウント設定」をクリックし、
青色枠の「プロライン『登録発生時送信』Webhook URL」を「コピー」ボタンで取得します。
https://あなたのドメイン/proline_webhook.php?account=senior
【プロライン管理画面での設定手順】
  1. プロラインフリー管理画面（PCブラウザ）にログインします。
  2. 左メニューの「外部連携・API」または「フォーム作成」「イベント予約」の設定を開きます。
  3. 「登録発生時に外部システムにデータを送信する」または「外部システム連携 (Webhook POST送信)」の入力欄に、上記でコピーしたURL（https://あなたのドメイン/proline_webhook.php?account=senior）を貼り付けます。
  4. 「保存」または「更新」をクリックして設定を完了します。
【自動反映される機能】
  • カルテの指導メモ（memo）へ自動追記: フォーム名、回答日時、各設問に対する回答内容が受講生カルテの「特記事項・指導メモ」へ自動的に整形されて追記保存されます。
  • レッスン予約日の自動反映: 予約イベントを受信した場合、次回レッスン日（oil_next_date）へ予約日時が自動セットされます。
  • 最終やり取り日時・プレビューの更新: 受講生一覧テーブルの「最終やり取り」列に最新のフォーム送信・予約イベントが即時反映されます。
  • スタッフ宛てリアルタイム通知: 管理者個人LINE、Discord、Slackへ「【フォーム回答】〇〇様がアンケートを送信しました」「【レッスン予約】〇〇様が予約を登録しました」と回答内容付きで即座にプッシュ通知されます。
  • 受講生カルテの自動新規作成: まだカルテに未登録の受講生であっても、プロラインの登録情報（LINE表示名、UID、お電話番号など）を元に自動で新規カルテが作成されるため、対応の抜け漏れが一切起きません。
プロライン共存時の安全・高速設計:
プロライン側がメッセージの自動返信（ReplyToken）を行うため、本システム側では受講生からの通常メッセージに対して自動返信を行わず、カルテの記録・最終やり取り日時の同期・リッチメニューの自動適用に専念します。これにより、LINEのReplyToken二重消費エラーを防止し、両システムが完全に共存します。また、複数ツールへの転送は並列非同期通信（curl_multi）で処理されるため、LINEサーバーへのレスポンスが一切遅延しません。

3. LINE受講生一括同期

LINE公式アカウントの全友だち情報を瞬時にカルテ一覧へ同期

LINE公式アカウントの友だちリスト（フォロー中の受講生）を自動取得し、受講生カルテ一覧に一括同期します。

1

ヘッダーの「LINE友だち一括同期」ボタンをクリック

管理画面上部にある緑色の「 LINE友だち一括同期」ボタンを押します。

2

リアルタイム進捗率（パーセント・件数）の可視化

同期中は専用の進捗プログレスダイアログが自動表示されます。
進捗率（0%〜100%）、処理件数（例: 150 / 300名）、新規登録数、情報更新数、および現在同期中の受講生名ストリームがリアルタイムに滑らかにアニメーション更新されます。

3

高速並列通信（curl_multi）＆分割バッチ処理

友だちが何百人・何千人いてもサーバーがタイムアウト（フリーズ）しないよう、15件ずつの分割バッチ処理と並列プロフィール取得を自動実行します。数十秒かかる大量のデータ同期も途切れることなく安全に完了します。

4

同期完了と自動カルテ更新

100%に達すると完了トーストとお祝いメッセージが表示され、最新のアイコン画像・受講生名がカルテ一覧へ自動反映されます。

4. 受講生カルテ・期日管理

受講コース、使用機器、次回レッスン、PC健康診断、会員更新期日の管理

受講生一覧テーブルでは、受講生ごとに必要なアクションを迅速に行えるよう、「4列 × 2行」の整然とした操作ボタングリッドを採用しています。全ボタンの高さ・幅・フォントサイズが統一され、直感的な配色で分かりやすく整理されています。

1

操作ボタングリッドの構成（4列 × 2行）

各受講生行の右端にある「操作」列には、8つの機能が整列配置されています：

  • 【上段1】💬 チャット（緑）: 受講生との1対1トーク履歴の確認、返信、未読バッジの確認
  • 【上段2】🎛️ メニュー（紫）: 次回期日メッセージを帯合成した個別リッチメニューの設定・解除
  • 【上段3】📢 お役立ち / 📋 アンケート（青）: シニア向け役立つ情報やDXアンケートの個別Flex送信
  • 【上段4】✏️ 編集（スレート）: カルテ編集モーダルを開き、受講コースや期日情報を更新
  • 【下段1】💻 レッスン（水色）: 次回レッスン案内のFlexリマインドLINEを送信
  • 【下段2】🔍 PC診断（エメラルド）: 定期PC健康診断案内のFlexリマインドLINEを送信
  • 【下段3】🗓️ 会員更新（橙）: 会員更新・月謝期日案内のFlexリマインドLINEを送信
  • 【下段4】🗑️ 削除（赤）: 受講生レコードの削除（誤登録や重複データの整理）
2

受講コース・使用機器・期日の入力

  • 受講生氏名: 受講生の実名（LINE名とは別に教室管理名として保持）
  • 受講コース名: 【シニア安心】パソコン入門コース、スマホ・タブレット活用コース、Word・Excel実用コースなど
  • 機器/会員番号: Windows 11 ノートPC、iPad Air、会員No.1024 など
  • 次回レッスン予定日: 次回予約している受講日時
  • 定期PC健康診断日: パソコンの動作チェック、空き容量整理、セキュリティ確認の推奨日
  • 会員更新・月謝期日: 月謝のお支払い期日または年次会員更新日
  • カルテメモ: 苦手な操作（文字入力、マウス操作）、受講進捗、特記事項
3

ページネーション（ページ分割表示）と高速検索

  • ページ分割表示: 受講生が1,000名規模に増えてもブラウザが重くならず快適に動作するよう、1ページあたり50件ずつのスマート分割表示を採用しています。
  • 表示件数の切り替え: テーブル下部のセレクターから「25件」「50件」「100件」「全件」をいつでもワンクリックで変更できます。
  • 高速デバウンス検索: 検索ボックスに受講生名やコース名を入力する際、入力確定を自動検知して高速フィルタリングを行い、ブラウザのフリーズを防ぎます。
4

表示カラムの選択（表示・非表示のカスタマイズ）

  • 表示項目の自由切替: ツールバーの「 表示項目」ボタンから、テーブルに表示したい列をチェックボックスでいつでも自由に切り替えられます。
  • 用途に合わせたスリム化: 例えば「チャット対応のみを行いたいときは期日列を隠す」「ノートPCなど画面幅が狭いときはメモ列を隠す」など、状況に応じた最適な表示レイアウトが作れます。
  • 設定の自動保存: 選択した表示設定はブラウザ（localStorage）に自動保存され、次回アクセス時やページ切り替え時も常に維持されます。「初期化」を押すといつでも全表示に戻せます。
期日バッジの色の見方 & 操作Tips:
・赤色: 期日超過、または当日〜7日以内の緊急ステータス
・黄色: 残り30日以内のリマインド推奨ステータス

5. 直近予定日の自動反映機能

次回レッスン・PC健康診断・会員更新のうち最も近い予定を自動判定

期日を入力すると、システムが自動的に今日から一番期日が近い予定を計算し、メッセージ帯を作成して受講生のLINE画面に反映します。

1

リアルタイムサマリー表示

日付を入力すると、フォーム下部に「最も期限が近い予定」が自動表示されます。
例: 「 次回レッスン: 2026-10-15 (あと8日)」

2

11. 複数LINE公式アカウントの切り替え・運用

シニアパソコン教室・アップファーレン店舗など、複数アカウントを1つの管理システムで統合運用

1

ヘッダーの「アカウント切替」からワンクリックで切り替え

管理画面（受講生カルテ）、リッチメニュー管理、操作マニュアルの画面上部ヘッダーに配置された「アカウント切替」ドロップダウンから、操作対象のLINE公式アカウント（例: シニア向けパソコン教室、アップファーレン等）をいつでも瞬時に切り替えることができます。
切り替えると、顧客一覧・リッチメニュー・店舗ロゴ・タイトルバッジが連動してそのアカウント専用のものに自動更新されます。選択したアカウントはブラウザに自動記憶され、次回ログイン時も直近のアカウントが維持されます。

💡 画面リロード不要のスマート同期:
アカウントを切り替えると、ページ全体を再読み込みすることなく、内部通信が自動的に対象アカウントへ切り替わり、該当アカウントの最新データが即時再読み込みされます。
2

データベース（DB）完全分離による安全設計

本システムは、アカウントごとに専用のSQLiteデータベースファイル（例: kureba-senior-system.db、kureba_kaisya_dx.db など）を完全に分離して管理しています。
これにより、顧客カルテや受講履歴、作成したリッチメニュー、配信履歴などが別のアカウントと混ざってしまう危険（データの交差汚染）を根本から防止しています。

3

各LINE公式アカウントの Webhook URL 設定

LINE公式アカウントごとに、LINE Developers コンソールの「Messaging API」設定内にある Webhook URL に以下のようにパラメータ（?account=アカウントキー）を付与して登録します：

  • シニア向けパソコン教室（デフォルト）:
    https://あなたのドメイン/webhook.php?account=senior（または末尾なしの webhook.php）
  • 会社DX・公式アカウント（kaisya_dx）:
    https://あなたのドメイン/webhook.php?account=kaisya_dx
  • アップファーレン（車両点検・店舗）:
    https://あなたのドメイン/webhook.php?account=upfahren

※登録後、LINE Developers の「検証」ボタンをクリックして「成功」と表示されることを確認し、「Webhookの利用」を必ずオン（有効）にしてください。
ブラウザで https://あなたのドメイン/webhook.php を直接開くと、登録されている全アカウントのWebhook URL設定一覧と現在の稼働状況をいつでも確認・コピーできます。

    'channel_secret' => 'LINE_CHANNEL_SECRET...',

12. 個別LINEチャット・メッセージ返信

受講生との1対1トーク履歴確認・直接Pushメッセージ返信機能の使い方

受講生からLINE公式アカウントへ届いたメッセージを管理画面上でリアルタイムに閲覧し、スタッフから受講生のLINEトーク画面へ直接返信メッセージを送信できる機能です。
プロラインの自動応答やステップ配信と一切競合せず、管理画面からいつでもスムーズな受講生サポートが可能です。

1

新着メッセージの確認と未読バッジ

受講生からメッセージが届くと、受講生一覧テーブルの受講生名横および「💬 チャット」ボタンに赤色の未読バッジ（件数）が表示されます。
「最終やり取り」カラムにもメッセージ内容のプレビューと受信日時が自動反映されます。

2

チャット画面の起動と会話履歴の確認

対象受講生の行にある「💬 チャット」ボタンをクリックすると、LINE風のチャットモーダルが開きます。
・受講生のメッセージは左側（白吹き出し）、スタッフからの返信は右側（緑吹き出し）に時系列で表示されます。
・画像やスタンプメッセージも分かりやすく表示され、画像をクリックすると拡大表示できます。
・チャット画面を開いた時点で未読フラグは自動的に既読として処理されます。
・チャットモーダルを開いている間は10秒ごとに自動更新（ポーリング）され、受講生からの最新メッセージが即座に反映されます。

3

メッセージの送信とクイック定型文

画面下のテキストエリアにメッセージを入力し、紙飛行機ボタンをクリックするか、キーボードの Ctrl + Enter（Macは Cmd + Enter）を押すと受講生のLINEトーク画面へプッシュ送信されます。
便利な定型文チップ（「挨拶」「確認中」「予約確認」「フォロー」）をクリックすると、ワンタップでよく使う返信文面を入力欄に自動挿入できます。

4

NEW送信者名（担当者名）の変更と表示スタイル選択（「from」の非表示対応）

チャット入力欄の上部にある「 送信者名」欄と「表示スタイル」ドロップダウンにより、受講生のLINE画面での見え方を完全にコントロールできます。

  • 1. 🚫 なし（from非表示・公式アカウント名そのまま）: 「from ~~~」という表示を一切出さず、通常のLINE公式アカウントからのすっきりとした吹き出しとして送信します。（「🚫 なし (from非表示)」チップを押すか空欄にするだけで即時適用）
  • 2. 💬 本文先頭に署名（【川合】など）: LINE側の英語「from」を出さずに、メッセージ本文の先頭に「【担当：川合】」や「【教室スタッフ】」と日本語で自然に担当者名を添えて送信します。最もおすすめの送信スタイルです。
  • 3. 🏷️ LINE Sender（from 名前）: LINE公式のSender機能を使い、受講生のLINE吹き出しの上に「from 川合」と小さく送信者名を表示します。
  • 前回の設定を自動記憶（localStorage）: 設定した送信者名と表示スタイルはブラウザに自動記憶され、次回以降もそのまま引き継がれます。
  • 管理画面チャット履歴への記録: 各吹き出しの下部にも送信担当者名が記録・表示され、誰が返信したかが一目で分かります。
プロライン共存の仕組み
本機能は、LINE Messaging APIのPush Messageを使用しています。受講生からのメッセージ受信時にもReplyTokenを消費しないため、プロラインの自動返信・ステップ配信・予約シナリオの動作を一切妨げません。

15. 会社DX 関心度アンケート配信・自動ヒアリング機能

LINEトーク画面上でワンタップ回答できる対話式アンケートと自動カルテ連携

1

機能の概要と目的

「会社DX」アカウントのLINE友だちに対し、企業のDX（デジタル化・業務効率化）への関心度や、具体的に興味のある分野を2ステップで手軽にヒアリングできる対話式アンケート機能です。LINEのリッチカード（Flex Message）を活用し、友だちが画面上の選択肢をタップするだけで回答が完了します。

2

2ステップ対話アンケートの流れ（自動応答）

友だちのLINEトーク画面上で以下のようにスムーズに進行します：

  • 【Q1: DX関心度】: 「🔥 大いにある（すぐにでも取り組みたい）」「💡 少しある（情報収集中・事例を知りたい）」「☕ 今はまだない（状況を見守り中）」の3択から選択。
  • 【Q2: 関心のあるテーマ・課題】: Q1で「大いにある」または「少しある」と答えた友だちに自動で表示。「💻 ペーパーレス化」「🤖 生成AI社内活用」「📱 LINE集客自動化」「📊 クラウド一元管理」「🤝 無料相談・他社事例」「✏️ その他」の中から興味のあるテーマをタップ。
3

管理画面からの配信手順（一斉配信 / 個別送信）

  1. 画面上部のアカウント切り替えで「会社DX」を選択します。
  2. ヘッダーの「📋 DXアンケート配信」ボタンをクリックすると配信スタジオが起動します。
  3. 「友だち全員に一斉配信」または「特定の顧客・担当者に個別送信」を選択します。顧客一覧の各行にある「📋 DXアンケート」ボタンから直接個別指定して送信することも可能です。
  4. 「このアンケートをLINE配信する」をクリックすると、確認ダイアログののち即座に対象者のトーク画面へFlex Messageが送信されます。
4

回答結果の自動保存・即時通知

  • カルテ自動保存: 回答された内容は、顧客カルテのメモ欄（staff_memo）および最新やり取り（last_interaction）に「【会社DXアンケート回答】関心度: 大いにある / 関心テーマ: 生成AI社内活用」として自動追記・タイムスタンプ保存されます。
  • 一覧テーブルでの回答済バッジ: アンケート回答済みの顧客には、一覧のメモ列に青い「📋 DXアンケート回答済」バッジが表示され、ひと目で未回答・回答済を判別できます。
  • 管理者LINE & Discord & Slack速報通知: 友だちが回答した瞬間に、管理者の個人LINE、DiscordおよびSlackへ「🏢 会社DX アンケート回答速報」が即時プッシュ通知されます。熱度の高い見込み客に対して即座に個別チャット等でアプローチできます。
キーワード自動応答にも対応
友だちがトーク画面で「アンケート」「dxアンケート」「DX相談」「効率化」などと入力した際にも、システムが自動的にこのQ1アンケートカードを返信します。配信を受け取っていなくても、興味を持った顧客がいつでも能動的にアンケートを回答できます。

16. メール二段階認証（2FA / セキュリティ）

管理者アカウントの不正ログイン防止・メールワンタイムパスワード

1

二段階認証のログイン手順

管理画面（受講生カルテ、リッチメニュー管理、操作マニュアル）へのログイン時、2段階の認証フローで安全に保護されます：
Step 1（管理者パスワード入力）：初期パスワード（1020143）を入力して「ログイン」をクリックします。
Step 2（メール認証コード入力）：パスワードが一致すると、自動的に登録メールアドレス（kawai@kureba.co.jp）宛てに6桁のワンタイム認証コードが送信されます。
Step 3（認証完了 & ログイン）：メールに届いた6桁コードを入力して「認証してログイン」をクリックすると、管理画面に入室できます。

2

有効期限・セキュリティ仕様

・認証コード有効期限：発行から10分間有効です。期限が切れた場合は「コード再送信」または最初からやり直してください。
・再送信タイマー：連続送信によるサーバー負荷や誤送信を防ぐため、60秒間のクールダウンタイマーが動作します。
・試行回数制限（ブルートフォース対策）：コードを5回連続で誤入力すると、セキュリティ保護のため認証セッションが自動失効します。
・ログイン状態の維持：認証に成功すると、ブラウザにセキュアな認証トークンが保持され、同一ブラウザで30日間安全に操作を継続できます。右上のログアウトボタンを押すことで即座に認証を取り消せます。

3

送信先メールアドレスの変更・設定

認証コードの送信先メールアドレスや有効期限の設定は、public_html/config.php 内で簡単にカスタマイズできます：
define('ADMIN_2FA_EMAIL', 'kawai@kureba.co.jp'); // 送信先メールアドレス
define('ADMIN_2FA_CODE_LIFETIME_MINUTES', 10); // 有効期限（分）
define('ENABLE_ADMIN_2FA', true); // 二段階認証の有効/無効トグル

ワンポイントTips: 全画面での認証共有
カルテ管理画面（index.html）、リッチメニュー管理（richmenu.html）、操作マニュアル（manual.html）のいずれかで一度二段階認証を完了すると、同一ブラウザ内であれば別画面へ移動した際も自動的に認証が引き継がれます。画面を切り替えるたびに毎回コードを入力する必要はありません。

17. よくある質問・トラブルシューティング

困ったときの解決方法

Q

3. サーバーのメール送信（sendmail / PHP mail）環境：サーバー側のメール送信制限やSPF/DKIM設定の影響を受けていないかご確認ください。

Q

プロライン側でメッセージが届かない、またはステップ配信が動かない時は？

以下の3点をご確認ください：
1. 管理画面右上の「プロライン連携」モーダルを開き、「プロライン転送を有効にする」にチェックが入っているか確認してください。

Q

プロラインと本システムで自動返信が競合することはありませんか？

競合しません。本システムの「プロライン転送」が有効な場合、受講生からのテキストメッセージに対する自動応答（ReplyTokenの消費）は完全に抑止され、プロライン側へ委ねられます。本システム側はカルテへの同期とプッシュ配信・リッチメニュー表示のみを行います。

Q

メニュー設定を変更したのに受講生のLINE画面が変わりません

LINEアプリの仕様上、トーク画面を開いたままの場合は画像キャッシュが残ることがあります。一度別のトーク画面やホーム画面に戻ってから、再度教室の公式アカウントトーク画面を開き直すと最新のメニューに即時更新されます。

Q

お役立ち情報配信で「送信失敗」と表示される場合はどうすればいいですか？

以下の点をご確認ください：
1. LINE公式アカウントの月間配信通数上限：LINE公式アカウント（無料プラン等）で月間の無料メッセージ通数枠（例: 月200通など）を超過している場合、LINEサーバーから配信制限エラーが返されます。その場合はLINE Official Account Managerより配信可能残数をご確認ください。
2. LINE未連携の受講生への個別送信：手動登録などでLINEと未連携（UIDがMANUAL_から始まる）の受講生には個別プッシュ送信ができません。「LINE友だち全員へ一斉配信」を利用するか、受講生に友だち登録およびマイカルテ連携をご案内ください。
3. エラー詳細の確認：送信失敗時には、LINEサーバーから返された具体的なエラー内容がダイアログに明示されます。内容をご確認のうえご対応ください。

Q

手動登録した受講生にチャットで返信できません

受講生一覧で「新規受講生登録」から手動作成された受講生は、LINEのユーザーID（U...）が未連携の状態です。受講生に教室のLINE公式アカウントを友だち追加していただき、マイカルテを開いてもらうか、メッセージを送信してもらうと自動的にLINE連携が完了し、チャット送受信が可能になります。

Q

Discord通知が届かない場合は？

以下の項目をご確認ください：
1. 管理画面上部の「Discord通知」設定モーダルを開き、Webhook URLが正しく入力されているか確認してください。
2. 「テスト通知を送信」ボタンを押し、緑色の成功バナーが出るか確認してください（Discord側でWebhookが削除されたり権限が変更されている場合はエラーが表示されます）。

Q

受講生数が1,000名近くなっても管理画面が重く・フリーズしない理由は？

スマートページネーション & イベント委譲：大量の受講生データ（900名超）を一括で描画するとブラウザのメモリやCPUを圧迫するため、当システムでは1ページあたり50件に分割描画するページネーションを搭載しています。また、ボタンごとの個別イベントバインドを廃止し、テーブル親コンテナでのイベント委譲処理を行うことで、極めて軽快な動作を実現しています。
検索デバウンス処理：検索ボックス入力時に過剰な再描画が発生しないよう、キー入力のタイピング完了を自動待機（250ms）してから絞り込みを実行するため、日本語入力中でもスムーズに検索できます。
