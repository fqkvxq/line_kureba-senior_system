プロライン (ProLine) ＆ 外部ツール Webhook中継・共存設定

LINE公式アカウントとプロライン等の拡張ツールを同時に共存させ、チャット通知やステップ配信を完全に維持

複数ツール共存・マルチWebhook中継の仕組み
LINE公式アカウントの仕様上、LINE DevelopersのWebhook URLは1つしか設定できません。
本システムをメインのWebhook窓口として設定し、受信したメッセージや友だち追加イベントを【プロライン】や【その他外部ツール】へリアルタイムに並列同時転送します。
これにより、プロラインのチャット通知・ステップ配信・個別返信を生かしたまま、本システムの受講生カルテ・予約管理・リッチメニューを完全共存させることができます。
※ プロライン管理画面（「初期設定」や「LINE公式アカウント連携」）で案内されるWebhook URLを貼り付けてください。
※ Zapier、Make、Lステップ、エルメ、自社サーバー等のURLも追加可能です。
※ 受講生がリッチメニューやマイカルテから開いた際、自動で ?uid=受講生のUID&name=お名前 が付与されます。
Webhook疎通テスト
入力されたすべてのWebhook URLへテスト通信を行い、正常に応答が返るか検証します。
LINE Developers（LINE公式）での設定手順
  1. LINE Developers コンソール にログイン。
  2. 対象チャンネルの「Messaging API設定」タブを開き、Webhook URL に以下を登録します：
    https://あなたのドメイン/webhook.php
  3. 「Webhookの利用」を ON（有効） にします。
  4. 上の「転送先 Webhook URL」にプロラインのWebhook URLを登録して保存すれば、共存設定完了です！
